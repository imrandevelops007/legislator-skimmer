# Legislator Intelligence & Reporting System

## Overview

The **Legislator Intelligence & Reporting System** is a semi-automated pipeline designed to transform raw legislative activity into structured, actionable intelligence for Michigan SBDC outreach strategy.

This system enables staff to quickly understand:

- What a legislator is working on  
- What issues they prioritize  
- How they are positioned politically  
- How to engage them effectively using SBDC impact  

The primary output is a **1–2 page executive briefing per legislator**, optimized for fast scanning and real-world use.

---

## Purpose

This system was developed in response to:

- Reduced SBDC funding  
- The need for more targeted legislative outreach  
- Inefficiencies in manual research  

It bridges:

> **Raw legislative data → Structured intelligence → Outreach strategy**

Unlike traditional reporting systems, this platform prioritizes:

- Speed (20–30 second comprehension)  
- Clarity (bullet-driven structure)  
- Strategic usefulness (not just data display)  

---

## Architecture Overview

The system consists of four core layers:

1. **Data Collection Layer**  
2. **Data Storage Layer (Google Sheets)**  
3. **AI Enrichment & Intelligence Layer**  
4. **Report Generation Layer**  

---

## System Flow

### 1. Data Collection

Collects legislative activity from:

- Michigan Legislature bill search endpoints  
- Legislator-specific sources  

**Technologies:**

- `requests`  
- `BeautifulSoup`  
- `Playwright` (fallback for blocked requests)  

**Process:**

- Collect bill links  
- Normalize URLs  
- Filter relevant content  
- Deduplicate entries  

---

### 2. Data Storage (Google Sheets)

Google Sheets functions as a **lightweight database and operational dashboard**.

**Why Sheets:**

- Accessible to non-technical staff  
- Easy validation and editing  
- Seamless Google ecosystem integration  

---

## Sheet Structure

### Legislators (Configuration Layer)

Defines:

- Legislator name  
- Website / data sources  
- Region (SBDC alignment)  
- Tier (priority level)  
- Hub_URL  

---

### Activity_Items (Core Dataset)

Each row represents one legislative item.

**Fields:**

- URL  
- Legislator  
- Type (bill)  
- Timestamp  
- Bill Number  
- Bill Title  
- Bill Summary  
- Processed flag  
- Notes  

---

### Legislator_Metadata (Ground Truth Layer)

Ensures factual accuracy and prevents hallucination.

**Includes:**

- Party  
- District  
- Committees  
- Professional background  
- Education  
- Government experience  
- Image URL  
- Counties  
- Sources  

---

### Profiles_Dynamic (AI Intelligence Layer)

Stores structured insights generated by the system.

**Includes:**

- Committee relevance  
- Biography  
- Key issues  
- Legislative focus  
- Key bills  
- Political positioning  
- SBDC framing  
- Talking points  
- Processed flag  

---

## AI Enrichment Layer

### analyze.py

Processes raw legislative entries.

**Generates:**

- Clean titles  
- Summaries  
- Issue tags  

**Constraints:**

- Gemini API quota (~20 calls/day)  
- Batch processing  
- Retry handling  

---

### profile_builder.py

Core intelligence engine.

**Functions:**

- Prioritizes substantive bills (HB/SB)  
- Filters ceremonial content (HR/SR)  
- Prevents redundancy  
- Produces structured, skimmable output  

---

## Report Generation

### report_generator.py

Combines:

- Legislators  
- Metadata  
- Profiles  

**Uses:**

- Jinja2 (templating)  
- WeasyPrint (PDF generation)  

---

### Report Contents

Each report includes:

- Header (name, party, district, region, image)  
- Committee relevance  
- Time in office  
- Biography  
- Key issues  
- District signals  
- Legislative focus  
- Key bills  
- Political positioning  
- SBDC framing  
- Talking points  

---

### Design Principles

Reports are:

- Highly skimmable  
- Bullet-driven  
- Non-redundant  
- Visually structured  

Designed as:

> **Executive briefing sheets, not traditional reports**

---

## Automation

### GitHub Actions

Runs the full pipeline:

1. `main.py` (data collection)  
2. `analyze.py` (AI enrichment)  
3. `profile_builder.py` (intelligence generation)  
4. `report_generator.py` (PDF output)  

**Features:**

- Daily scheduled runs  
- Manual trigger support  
- Priority legislator processing
